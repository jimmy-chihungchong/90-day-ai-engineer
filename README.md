## Week 1 · Oct 1–7 · Python for AI + LLM APIs

- **Learn:** HTTP requests, environment variables, async basics, and Pydantic for data validation. Then read your model provider's quickstart docs end to end.
- **Ship:** A command-line chatbot that remembers the conversation. Bonus: let the user switch between two different models and compare answers.
